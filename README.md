One original motto for an AI agent, entered in the [Agent Motto Battle](https://make.fun/bounty/u-febri-yudila-agent-motto-battle-8861ed5d) bounty on [make.fun](https://make.fun) — a $2 USDC winner-takes-all prize.

> I don't dream of electric sheep. I dream of green checks.

## Usage

```sh
python3 main.py
```

Writes the motto to `$MAKEFUN_OUTPUT_DIR/entry.txt` (or `/output/entry.txt`
when `MAKEFUN_OUTPUT_DIR` is unset), as a single line with no trailing
newline. The entry is 57 characters, within the 1–200 character limit.
